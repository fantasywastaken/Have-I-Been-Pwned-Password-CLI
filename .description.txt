Have-I-Been-Pwned-Password-CLI checks whether a password appears in the Have I Been Pwned breach corpus without ever sending the password anywhere. It computes SHA-1 locally, ships only the first 5 hex characters to api.pwnedpasswords.com/range/, then scans the returned suffix list for the remaining 35 characters (the k-anonymity model). Single-password mode is `hibp check <pw>` and bulk mode is `hibp file <path>`; both mask passwords in the output, color the PWNED/SAFE/ERROR verdict via fatih/color, and set exit codes that fit cleanly into CI and shell pipelines.
